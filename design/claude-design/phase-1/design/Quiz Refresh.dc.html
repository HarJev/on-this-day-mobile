On This Day · Visual refresh · Phase 1 of 2

The quiz, made calmer to read and more satisfying to play

Same palette, same two-tab navigation, same screens. The changes are in rhythm and feedback: each question type now has its own label and answer treatment, answers sit high enough to be tapped without scrolling, the moment of answering has a clear reveal with the year or context attached, and results show the round question by question instead of a single number.

Start with the playable flow below, then the static boards for every screen and state. Components and motion notes are at the bottom.

5Components
Answer row
Min height 56, wraps to any length. State always carries an icon and a text tag, never colour alone. Used as a 2×2 grid for image questions.

6Motion
Commit an answer
Tapped row fills and thickens its border in 120 ms. The badge swaps letter for check or cross with a 160 ms crossfade and a 0.9 → 1 scale, ease-out, no overshoot. Other rows fade to their dimmed state over 200 ms. Light haptic on commit.
Feedback panel
Slides up 16 px while fading in, 220 ms, cubic-bezier(.2,.7,.2,1). Focus moves to the panel title for screen readers, which announce "Correct" / "Incorrect" plus the answer.
Ordering
Dragged row lifts (shadow, 1% scale) and neighbours slide 180 ms. Arrow buttons animate the same swap. On submit, years fade in row by row with a 40 ms stagger, then node marks appear. Selection haptic on each swap.
Between questions
Question and answers crossfade with a 12 px leftward shift, 200 ms. The current progress segment fills from stone to cobalt over 240 ms; the previous one settles to ink.
Results
Strip cells reveal left to right with a 30 ms stagger. The score appears fully formed; no count-up, no confetti.
Reduced motion
All translations and scales removed. State changes become 100 ms opacity crossfades or instant. Stagger removed. Haptics unchanged (system setting governs).
